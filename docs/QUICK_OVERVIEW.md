## 🔑 Commandes Rapides

### Démarrer le projet (Docker)

```bash
# Windows
quickstart.bat

# Linux/Mac
./quickstart.sh
```

### Développement local

**Backend**

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

**Frontend**

```bash
cd frontend
npm install
npm run dev
```

### Accès

- 🌐 Frontend : http://localhost:3000
- 🔧 Backend : http://localhost:8000
- 📚 API Docs : http://localhost:8000/docs
